# RedPen 2.0

This repository is the new RedPen 2.0 working repository. Its initial snapshot copies the complete 92-file application from [`innocentmaweta-hub/vercel-redpen2`](https://github.com/innocentmaweta-hub/vercel-redpen2) so the existing interface, page structure, styling, assets, and interactions can be preserved as the reference baseline.

The initial snapshot is intentionally kept identical to the reference application. Subsequent work can separate the UI from legacy implementation details and rebuild the internals without losing the original interface.
